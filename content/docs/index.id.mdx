Devid adalah lingkungan pengembangan lokal untuk aplikasi PHP dan Node.js di macOS dan di Linux (Ubuntu, serta Arch Linux dan distribusi turunannya). Setiap folder yang Anda link atau park disajikan di `https://<name>.test` dengan sertifikat tepercaya. Devid menjalankan PHP 8.3, 8.4, 8.5 dan 8.6 berdampingan, dengan nginx, Caddy atau Apache sebagai web server. Aplikasi Node.js, Vite dan Next.js disajikan lewat dev server Anda sendiri, yang bisa dijalankan dan dihentikan Devid untuk Anda. Devid juga bisa menangkap email yang dikirim aplikasi Anda ke sebuah inbox di komputer Anda, dan menjalankan MySQL, PostgreSQL dan MongoDB untuknya. Devid tidak butuh Homebrew, Docker, atau mesin virtual. Anda memakainya dari command line, dari antarmuka terminal (TUI), atau, di macOS, dari aplikasi desktop.

Devid adalah open source dengan lisensi [GNU AGPL v3](https://github.com/hadziqmtqn/devid/blob/main/LICENSE). Kode sumbernya ada di [hadziqmtqn/devid](https://github.com/hadziqmtqn/devid); rilisnya ada di [devid-binaries](https://github.com/hadziqmtqn/devid-binaries), dan laporan bug dikirim ke [issues devid](https://github.com/hadziqmtqn/devid/issues/new/choose).

<Callout type="warn" title="Proyek pribadi, disediakan apa adanya">
  Devid berjalan di Mac Intel dan Apple silicon, di Ubuntu 24.04 dan 26.04, dan di Arch Linux (x86_64). Devid diuji secara manual di M1 dengan macOS 26, di Intel dengan macOS 14, serta di Ubuntu 24.04, Arch Linux dan CachyOS. `devid setup` meminta password Anda sekali dan mengubah pengaturan sistem: mengarahkan pencarian `.test` ke Devid, memercayai certificate authority Devid, dan meneruskan port 80 dan 443. `devid uninstall` membatalkan semuanya. Build macOS ditandatangani secara ad-hoc dan tidak dinotarisasi.
</Callout>

## Instalasi [#install]

Dengan aplikasi desktop:

```sh
curl -fsSL https://github.com/hadziqmtqn/devid-binaries/releases/download/devid-latest/install.sh | sh -s -- --gui
```

Tanpa aplikasi desktop (hanya CLI dan TUI):

```sh
curl -fsSL https://github.com/hadziqmtqn/devid-binaries/releases/download/devid-latest/install.sh | sh
```

Di Linux, instal dulu beberapa paket (lihat [Linux](/docs/linux)). Di Ubuntu:

```sh
sudo apt install curl libnss3-tools
curl -fsSL https://github.com/hadziqmtqn/devid-binaries/releases/download/devid-latest/install.sh | sh
```

Di Arch Linux dan CachyOS:

```sh
sudo pacman -S --needed curl nss nftables
curl -fsSL https://github.com/hadziqmtqn/devid-binaries/releases/download/devid-latest/install.sh | sh
```

Lalu buka terminal baru dan sajikan proyek Anda:

```sh
devid park ~/Projects
devid doctor
```
