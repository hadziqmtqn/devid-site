title: Introduction
description: Local PHP and Node.js development for Intel and Apple silicon Macs and for Linux (Ubuntu and Arch). Every project gets its own https:// address.
---

Devid is a local development environment for PHP and Node.js apps on macOS and on Linux (Ubuntu, and Arch Linux and the distributions built on it). Every folder you link or park is served at `https://<name>.test` with a trusted certificate. Devid runs PHP 8.3, 8.4, 8.5 and 8.6 side by side, and nginx, Caddy or Apache as the web server. Node.js, Vite and Next.js apps are served through your own dev server, which Devid can start and stop for you. Devid can also catch the mail your apps send, in an inbox on your computer, and run MySQL, PostgreSQL and MongoDB for them. It needs no Homebrew, no Docker and no virtual machine. You use it from the command line, from a terminal UI (TUI) or, on macOS, from the desktop app.

Devid is open source under the [GNU AGPL v3](https://github.com/hadziqmtqn/devid/blob/main/LICENSE). The source is in [hadziqmtqn/devid](https://github.com/hadziqmtqn/devid); the releases are in [devid-binaries](https://github.com/hadziqmtqn/devid-binaries), and bug reports go to [devid's issues](https://github.com/hadziqmtqn/devid/issues/new/choose).

<Callout type="warn" title="A personal project, provided as is">
  Devid runs on Intel and Apple silicon Macs, and on Ubuntu 24.04 and 26.04 and on Arch Linux (x86_64). It is tested by hand on an M1 with macOS 26, on Intel with macOS 14, and on Ubuntu 24.04, Arch Linux and CachyOS. `devid setup` asks for your password once and changes system settings: it sends `.test` lookups to Devid, trusts Devid's certificate authority and forwards ports 80 and 443. `devid uninstall` undoes all of it. The macOS builds are ad-hoc signed and not notarized.
</Callout>

## Install

With the desktop app:

```sh
curl -fsSL https://github.com/hadziqmtqn/devid-binaries/releases/download/devid-latest/install.sh | sh -s -- --gui
```

Without it (the CLI and TUI only):

```sh
curl -fsSL https://github.com/hadziqmtqn/devid-binaries/releases/download/devid-latest/install.sh | sh
```

On Linux, install a few packages first (see [Linux](/docs/linux)). On Ubuntu:

```sh
sudo apt install curl libnss3-tools
curl -fsSL https://github.com/hadziqmtqn/devid-binaries/releases/download/devid-latest/install.sh | sh
```

On Arch Linux and CachyOS:

```sh
sudo pacman -S --needed curl nss nftables
curl -fsSL https://github.com/hadziqmtqn/devid-binaries/releases/download/devid-latest/install.sh | sh
```

Then open a new terminal and serve your projects:

```sh
devid park ~/Projects
devid doctor
```
