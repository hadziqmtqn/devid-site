title: Terminal commands
description: "Run Devid's PHP, Composer, nginx, Caddy and Mailpit by name, from any terminal, editor or script."
---

Devid keeps its commands in `~/.devid/bin`. With that folder on your `PATH`, a terminal runs them by name:

| Command | Runs |
|---|---|
| `devid` | The CLI, or the TUI with no arguments |
| `php`, `composer` | The PHP version of the site you are in, or the default (see [PHP](/docs/php)) |
| `php8.3`, `php8.4`, `php8.5`, `php8.6` | That PHP version, wherever you are, with Devid's `php.ini` |
| `nginx` | Devid's nginx on Devid's config: `nginx -t`, `nginx -T`, `nginx -s reload`, `nginx -V` |
| `caddy` | Devid's Caddy, for example `caddy version` |
| `mailpit` | Devid's Mailpit; `mailpit sendmail` delivers to Devid's inbox |

`php8.3`–`php8.5`, `nginx`, `caddy` and `mailpit` come with Devid 0.16, and `php8.6` with Devid 0.20.1. Earlier versions have `devid`, `php` and `composer`.

## Add to PATH

Setup puts the folder on your `PATH`. To add it again, or to take it out:

- **Desktop app:** Settings › Terminal › **Add to PATH** (or **Remove from PATH**). The section lists the commands.
- **CLI:** `devid path on` or `devid path off`. `devid path` shows whether new terminals get the commands, and lists them. It works while the daemon is stopped.
- **TUI:** `p` on the Settings page.

It adds one line, marked `# added by devid`, to `~/.zshenv` and `~/.zshrc` (with bash, to `~/.bash_profile`; on Linux with bash, to `~/.bashrc` and to `~/.bash_profile` if you have one, otherwise `~/.profile`):

```sh
export PATH="/Users/you/.devid/bin:$PATH" # added by devid
```

With fish as your shell, the line goes to its own file, `~/.config/fish/conf.d/devid.fish`, on macOS and Linux:

```fish
fish_add_path --global --move --path '/Users/you/.devid/bin' # added by devid
```

- `~/.zshenv` reaches every zsh, including the ones that editors, scripts and tools start.
- `~/.zshrc` keeps Devid's commands ahead of Homebrew's in a terminal. macOS reorders `PATH` after reading `~/.zshenv`, so this second line is what puts Devid first.
- A terminal window that was open before the change keeps its old `PATH`. Open a new one, or run `exec zsh`.
- **Remove from PATH** and `devid path off` delete only the lines Devid added.

## Notes

- **nginx:** Devid starts and stops nginx itself (`devid start|stop|restart nginx`). The `nginx` command only tests, shows or signals it. A plain `nginx` is refused, so a second copy never starts.
- **Mailpit:** Devid downloads it the first time you turn on [Mail](/docs/mail). `mailpit sendmail` sends to the SMTP port in Devid's settings, unless you pass `-S <host:port>`.
- **Not installed yet:** a command whose program is missing says how to install it, for example `devid php install 8.4` or `devid server install caddy`.
- **Your own copies:** Devid's folder comes first on `PATH`, so its `nginx`, `caddy` and `mailpit` hide Homebrew's. Call the other copy by its full path, or run `devid path off`.
