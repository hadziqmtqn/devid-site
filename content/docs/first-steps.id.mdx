```sh
devid park ~/Projects          # setiap subfolder menjadi <folder>.test
devid doctor                   # periksa apakah semuanya berjalan
```

Lalu buka `https://<folder>.test` di browser Anda. Kalau folder itu punya subfolder `public/` (Laravel, Symfony), Devid menyajikan subfolder itu; kalau tidak, Devid menyajikan folder itu sendiri.
