---

Everything lives in `~/.devid`:

| Path | Contents |
|---|---|
| `bin/` | `devid`, plus `php`, `composer`, `php8.3`–`php8.6`, `nginx`, `caddy`, `mailpit` and the clients of installed databases (hard links to `devid`; see [Terminal commands](/docs/terminal)) |
| `config.toml` | Settings: `.test` domain, web server, default PHP, ports (8088/8443 behind pf or, on Linux, nftables; DNS 53535), parked folders, links, isolated and ignored sites, `autostart`, `update_check_minutes`, and per site under `[apps.<site>]` its type changes, local port and commands. Prefer the commands to editing it. |
| `php/<version>/` | PHP binaries, `etc/php.ini` (yours to edit), `etc/conf.d/` (switches for Xdebug, pcov and catalog extensions) |
| `php-ext/<version>/` | Catalog extensions (`devid php ext install`), one folder each |
| `nginx/`, `caddy/`, `apache/` | Web server binaries and generated configs (rewritten by Devid) |
| `ca/`, `certs/` | The local CA, the CA bundle and per-site certificates |
| `db/` | Database programs, one folder per series (`mysql-8.4/`), and `mongosh/` (see [Databases](/docs/databases)) |
| `data/` | Each database series' data, and the passwords Devid keeps for its accounts. `devid uninstall --purge` keeps it |
| `log/` | Daemon, php-fpm, web server and database logs, each command's (`app-<site>-<name>.log`) and each share's (`share-<site>.log`) |
| `run/` | The daemon socket and pid files, including running commands', and the databases' sockets |
