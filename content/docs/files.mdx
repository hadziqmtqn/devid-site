---

Everything lives in `~/.devid`:

| Path | Contents |
|---|---|
| `bin/` | `devid`, plus `php` and `composer` (hard links to `devid`) |
| `config.toml` | Settings: `.test` domain, web server, default PHP, ports (8088/8443 behind pf, DNS 53535), parked folders, links, isolated and ignored sites, `autostart`, `update_check_minutes`, and per site under `[apps.<site>]` its type changes, local port and commands. Prefer the commands to editing it. |
| `php/<version>/` | PHP binaries, `etc/php.ini` (yours to edit), `etc/conf.d/` (switches for Xdebug, pcov and catalog extensions) |
| `php-ext/<version>/` | Catalog extensions (`devid php ext install`), one folder each |
| `nginx/`, `caddy/`, `apache/` | Web server binaries and generated configs (rewritten by Devid) |
| `ca/`, `certs/` | The local CA, the CA bundle and per-site certificates |
| `log/` | Daemon, php-fpm and web server logs, each command's (`app-<site>-<name>.log`) and each share's (`share-<site>.log`) |
| `run/` | The daemon socket and pid files, including running commands' |
